# Предложение экрана грамматической практики

Статический интерактивный прототип для согласования, без API и доступа к аккаунту. Открыть `index.html` или запустить из корня `python3 -m http.server 5180 --bind 127.0.0.1 --directory design/practice`.

Сценарий: заметная «Практика» в навигации и вход с «Сегодня» → выбор собственной подтверждённой темы → подготовка заданий → короткая тренировка → результат и добровольный повтор ошибок. Объяснение открывается только по желанию. На странице грамматики отдельно видны «Теория» и «Тренироваться».

В прототипе можно переключать тему, выбрать один из трёх учебных примеров, проверить ответ и открыть пример итогового экрана. Список тем, 5 заданий и итог 4/5 иллюстративны; это не данные аккаунта и не полноценное занятие.

Перед реализацией нужно согласовать экран. Затем: разделить доступность заданий и теории на сервере, сохранить существующие задания/попытки при генерации объяснения, добавить состояния подготовки/ошибки/повтора и пустого списка, входы с главной/навигации/темы. Светлая/тёмная палитра и типографика взяты из текущих токенов проекта. Реальный UI собирать на существующих React-компонентах и Tailwind.
