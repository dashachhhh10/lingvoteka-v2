# Lingvoteka

Личная платформа для материалов уроков итальянского: загрузка, проверяемое AI-извлечение слов и тем, интервальное повторение, теория и упражнения. Интерфейс на русском, задания на итальянском. Код разделён на React-клиент (`apps/web`) и NestJS API (`apps/api`); данные принадлежат пользователю, а состояние повторения хранится отдельно для каждого аккаунта.

## Запуск локально

Нужны Node.js 22+, pnpm 11 и PostgreSQL. Создай базу `lingvoteka` и выполни:

```sh
pnpm install
cp .env.example apps/api/.env
# Отредактируй apps/api/.env: DATABASE_URL и BETTER_AUTH_SECRET обязательны.
pnpm db:migrate
pnpm dev
```

Если pnpm блокирует установочные скрипты Prisma или esbuild, выполни `pnpm approve-builds`, разреши их и повтори `pnpm install` и `pnpm db:migrate`.

Фронтенд откроется на `http://localhost:5173`, API — на `http://localhost:3001/api`. Vite проксирует `/api`, поэтому браузер работает с одним origin. `pnpm dev` запускает также отдельный worker: API ставит разбор материалов в очередь pg-boss, worker выполняет его и сохраняет черновик. Очередь живёт в PostgreSQL; закрытие страницы или перезапуск API не теряет задание. Для production запусти API (`pnpm --filter @lingvoteka/api start`) и worker (`pnpm --filter @lingvoteka/worker start`) как отдельные процессы. Им нужны одна постоянная PostgreSQL и общий постоянный том для `UPLOAD_DIR`.

`BETTER_AUTH_SECRET` должен содержать не менее 32 случайных символов. Пока SMTP не настроен полностью или сервер отклоняет авторизацию, в режиме разработки письмо не отправляется: ссылка подтверждения появляется прямо после регистрации (и при повторном запросе на экране входа), а ссылка сброса пароля — в терминале API. Локальная ссылка доступна через API только с этого компьютера. Для настоящей доставки укажи `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD` и `SMTP_FROM` в `apps/api/.env`, затем перезапусти API. При запуске сервер проверяет SMTP-авторизацию; в production при её ошибке API не запускается. Для production также нужен `REGISTRATION_INVITE_CODE`; поле кода показано при регистрации. Не публикуй `.env` и не используй пример секрета из `.env.example`.

Для разбора материалов, генерации теории и упражнений задай `GEMINI_API_KEY`. Модель настраивается через `GEMINI_MODEL` (по умолчанию `gemini-3.5-flash`). Без ключа материалы и записи можно добавлять вручную; AI-действия покажут явную ошибку. Ключ остаётся только на сервере. При использовании AI текст и файлы уроков передаются в Gemini.

## Основной сценарий

1. Добавь материал: текст и/или до пяти файлов. Поддерживаются TXT, DOCX, PPTX, PDF, JPG и PNG; один файл до 10 МБ, суммарно до 20 МБ. Google-тест и онлайн-доску можно экспортировать в PDF, сохранить скриншотом или скопировать как текст.
2. AI предложит слова и грамматические темы в фоновом задании. Можно закрыть страницу и вернуться к результату. Проверка обязательна: исправь, удали или добавь записи перед сохранением. Если AI недоступен, тот же экран позволяет заполнить их вручную.
3. Новые слова появляются в словаре и очереди повторения. Планировщик FSRS сохраняет отдельное состояние и историю каждого пользователя; за день вводится до 10 новых карточек. Просроченные карточки идут первыми.
4. В грамматике открой тему и создай краткую теорию с упражнениями. AI-объяснение явно помечено. Ответ проверяется на сервере, после чего показываются правильный вариант и пояснение.

Исходные файлы хранятся локально и скачиваются только через защищённый маршрут владельца. PDF и изображения читаются моделью визуально. Из DOCX и PPTX извлекается текст и встроенные JPG/PNG; если изображений слишком много или они слишком велики, приложение предложит экспортировать документ в PDF. Произвольные ссылки на Google-тесты не импортируются. AI-ответы могут быть ошибочными, поэтому требуется ручная проверка извлечения и явная пометка теории.

## Проверки

```sh
pnpm typecheck
pnpm build
```

Схема базы и миграции — в `apps/api/prisma`. Настройки темы сохраняются в аккаунте и локальном браузере. Анимации переходов сделаны с GSAP и отключаются при `prefers-reduced-motion`.

Основа FSRS: [ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs). Ввод PDF/изображений и JSON-ответов: [документация Gemini](https://ai.google.dev/gemini-api/docs/document-processing), [структурированные ответы](https://ai.google.dev/gemini-api/docs/structured-output).
