# Lingvoteka

Личная платформа для материалов уроков итальянского: загрузка, проверяемое AI-извлечение слов и тем, интервальное повторение, теория и упражнения. Интерфейс на русском, задания на итальянском. Код разделён на React-клиент (`apps/web`) и NestJS API (`apps/api`); данные принадлежат пользователю, а состояние повторения хранится отдельно для каждого аккаунта.

## Запуск локально

Нужны Node.js 22+, pnpm 11 и PostgreSQL. Создай базу `lingvoteka` и выполни:

```sh
pnpm install
cp .env.example apps/api/.env
# Отредактируй apps/api/.env: DATABASE_URL и BETTER_AUTH_SECRET обязательны.
pnpm db:migrate
pnpm dev
```

Если pnpm блокирует установочные скрипты Prisma или esbuild, выполни `pnpm approve-builds`, разреши их и повтори `pnpm install` и `pnpm db:migrate`.

Фронтенд откроется на `http://localhost:5173`, API — на `http://localhost:3001/api`, документация API — на `http://localhost:3001/api/docs` (JSON: `/api/openapi.json`). Vite проксирует `/api`, поэтому браузер работает с одним origin. `pnpm dev` запускает также отдельный worker: API ставит в очередь pg-boss разбор материалов и генерацию теории с упражнениями. Worker также определяет категории новых слов, добавленных вручную. Очереди живут в PostgreSQL; закрытие страницы или перезапуск API не теряет задания. Для production запусти API (`pnpm --filter @lingvoteka/api start`) и worker (`pnpm --filter @lingvoteka/worker start`) как отдельные процессы. Им нужны одна постоянная PostgreSQL и доступ к одному закрытому S3-совместимому бакету.

Локально файлы по умолчанию хранятся в `UPLOAD_DIR`. Для S3 укажи `FILE_STORAGE=s3`, `S3_BUCKET` и `S3_REGION`; для другого S3-совместимого сервиса добавь `S3_ENDPOINT`. Пару `S3_ACCESS_KEY_ID`/`S3_SECRET_ACCESS_KEY` указывай вместе либо используй стандартный источник учётных данных AWS SDK (например, IAM role). API и worker должны получать одинаковые настройки. В production S3 обязателен, а сторонний endpoint должен использовать HTTPS. Бакет должен быть закрытым: публичный доступ отключён, приложению нужны только права на запись, чтение и удаление объектов в своём префиксе `materials/`. Клиент скачивает файл через API после проверки владельца; прямых публичных ссылок нет. Уже загруженные локальные файлы продолжают читаться по старым путям, если их том доступен API и worker; автоматического переноса в S3 пока нет.

`BETTER_AUTH_SECRET` должен содержать не менее 32 случайных символов. Регистрация и вход сейчас работают без подтверждения почты и без проверочного письма. Адрес нужен для входа и восстановления пароля. Если SMTP не настроен или временно недоступен, в режиме разработки ссылка сброса пароля появится в терминале API; для настоящей доставки укажи `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD` и `SMTP_FROM` в `apps/api/.env`, затем перезапусти API. При запуске сервер проверяет SMTP-авторизацию; в production при её ошибке API не запускается. Для production также нужен `REGISTRATION_INVITE_CODE`; поле кода показано при регистрации. Не публикуй `.env` и не используй пример секрета из `.env.example`.

Для разбора материалов, генерации теории и упражнений задай `GEMINI_API_KEY`. Модель настраивается через `GEMINI_MODEL` (по умолчанию `gemini-3.5-flash-lite`). Без ключа материалы и записи можно добавлять вручную; AI-действия покажут явную ошибку. Ключ остаётся только на сервере. При использовании AI текст и файлы уроков передаются в Gemini.

## Основной сценарий

1. Добавь материал: текст и/или до пяти файлов. Поддерживаются TXT, DOCX, PPTX, PDF, JPG и PNG; один файл до 10 МБ, суммарно до 20 МБ. Название подставляется из имени первого файла без расширения, его можно изменить. Google-тест и онлайн-доску можно экспортировать в PDF, сохранить скриншотом или скопировать как текст.
2. AI предложит слова и грамматические темы в фоновом задании. Можно закрыть страницу и вернуться к результату. Проверка обязательна: исправь, удали или добавь записи перед сохранением. Если AI недоступен, тот же экран позволяет заполнить их вручную.
3. Новые слова появляются в словаре и очереди повторения. AI предлагает для каждого слова часть речи и лексическую тему (например, «Существительное» и «Спорт»); обе категории можно поправить при проверке материала. В словаре можно группировать слова по любой из этих осей, выбрать группу и искать слово. Для ранее сохранённых слов обработка начинается только после нажатия кнопки «Определить темы для слов без категории»; слова и переводы при этом передаются Gemini. Нажми на карточку, чтобы перевернуть её; после просмотра перевода смахни влево («не помню») или вправо («помню») либо выбери одну из четырёх оценок. Планировщик FSRS сохраняет отдельное состояние и историю каждого пользователя; за день вводится до 10 новых карточек. Просроченные карточки идут первыми.
4. В грамматике открой тему и создай краткую теорию с упражнениями. Генерация выполняется в фоне; можно закрыть страницу и вернуться позже. AI-объяснение явно помечено. Ответ проверяется на сервере, после чего показываются правильный вариант и пояснение.

Исходные файлы скачиваются только через защищённый маршрут владельца. PDF и изображения читаются моделью визуально. Из DOCX и PPTX извлекается текст и встроенные JPG/PNG; если изображений слишком много или они слишком велики, приложение предложит экспортировать документ в PDF. Произвольные ссылки на Google-тесты не импортируются. AI-ответы могут быть ошибочными, поэтому требуется ручная проверка извлечения и явная пометка теории.

## Проверки

```sh
pnpm typecheck
pnpm build
```

Схема базы и миграции — в `apps/api/prisma`. Настройки темы сохраняются в аккаунте и локальном браузере. Декоративная лоза мягко реагирует на смену раздела с помощью GSAP; при `prefers-reduced-motion` движение отключается.

Основа FSRS: [ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs). Ввод PDF/изображений и JSON-ответов: [документация Gemini](https://ai.google.dev/gemini-api/docs/document-processing), [структурированные ответы](https://ai.google.dev/gemini-api/docs/structured-output).
