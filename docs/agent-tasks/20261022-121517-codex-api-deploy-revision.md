## Решения и результат

Официальная документация Railway описывает runtime-переменную `RAILWAY_GIT_COMMIT_SHA` для GitHub-деплоев. Добавлено публичное поле `revision` в `/api/health`, равное этому SHA или `null` вне GitHub-деплоя. Поле `status` сохранено; секреты не раскрываются.
