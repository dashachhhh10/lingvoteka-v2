## Решения и результат

- Единый источник `BOT_COMMANDS` в telegram-message.ts: из него берутся setMyCommands (меню `/`), распознавание команд и список в /start — чтобы они не расходились.
- /start: без абзаца «В чате / В приложении», с блоком «Команды» — Telegram сам делает `/команда` в тексте кликабельной. Inline-кнопки (в т.ч. «Открыть приложение ↗») остаются.
- Порядок в меню `/`: phrase, add, cards, materials, app, help, start (действия первыми, как в образце). Описания укорочены для меню. Тест «start copy…» проверяет, что каждая команда из BOT_COMMANDS распознаётся и (кроме start) есть в /start, а «Меню» в /start нет.
