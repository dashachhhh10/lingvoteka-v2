## Цель и уточнения пользователя

Адаптировать приложенный liquid-morph-floating-menu для меню после регистрации и переходов между страницами. Основной экран — «Сегодня». Сохранить стек и нашу палитру.

Пользователь разрешила предложить более подходящий вариант. Выбран функциональный экран «Сегодня»: главный следующий шаг, карточка слова при наличии очереди и быстрые ссылки в материалы, словарь и грамматику.

## Решения и результат

Вложение содержит меню на Framer Motion и демонстрационный skeleton. Поведение перенесено на существующие React Router, Tailwind и CSS transitions; зависимости не добавлялись. Главная после входа открывается на `/`; публичный лендинг сохранён. Реализована стартовая страница с планом из API и ссылками в разделы. Повторение сохраняет отдельный учебный экран со своим возвратом.

Вместо верхних вкладок и мобильной панели — единое плавающее меню: Сегодня, Материалы, Словарь, Карточки, Грамматика, Профиль. Закрытая кнопка показывает текущий раздел. Раскрытие поверхности, заполнение цветом и прокрутка букв адаптированы к существующей палитре. Есть active-state, нативные ссылки, inert для скрытой панели, Escape, закрытие снаружи и при уходе фокуса. Клавиатурное раскрытие фокусирует первую ссылку, Tab позволяет выйти без ловушки. Reduced motion отключает движение; темы берутся из токенов. AppShell переводит фокус на main и прокручивает вверх при смене пути, страницы появляются через существующий PageMotion. Для ошибки загрузки плана добавлена кнопка повторной попытки.

Активные задачи других агентов прочитаны; планируемые файлы не пересекаются. Общие project-context и roadmap заняты другими задачами, решение сохранено здесь.
