## Проверки

Пройдены новые 7 unit-тестов, включая настройку команд/меню/webhook, неизменность production-webhook при локальном старте и секрет, одинаковый между перезапусками. Повторно пройдены typecheck, build, format:check, git diff --check. test:telegram-auth прошёл с синтетическими локальными аккаунтами и cleanup; первая sandbox-попытка не имела доступа к localhost, повтор с сетевым разрешением успешен. Реальный getMe подтвердил @LingvotekaApp в журнале production 13:06+08. setMyCommands/setChatMenuButton/setWebhook получили успешные ответы; финальная проверка сохранённых адресов не прошла. Предполагаемая причина — нормализация корневого URL с добавлением завершающего slash. Сравнение меню переведено на URL.href; добавлен регрессионный тест с завершающим slash и отказом для других путей. Окончательный результат настройки ожидается после следующего деплоя. Токен остаётся только в Railway; .env не менялись.
