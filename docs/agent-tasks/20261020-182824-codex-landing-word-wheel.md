## Цель и уточнения пользователя

В отдельной ветке сделать новый публичный лендинг. Адаптировать приложенный React-компонент WorksWheel под карточки итальянских слов, смягчить его цветовое направление и распространить палитру, типографику и отступы через Tailwind-тему на остальной интерфейс. Стек сохранить.

## Решения и результат

Новая ветка создана от origin/dev в отдельном worktree. Приложенный компонент использует абстрактные Tailwind-токены и внешние демонстрационные картинки; конкретной палитры и шрифта в нём нет. Дизайн направления выводим из существующих оливково-лимонных токенов Lingvoteka и кинетики колеса, без внешних картинок. Общие docs/project-context.md и AGENTS.md пока не попали в ветку, потому что они неотслеживаемые файлы другой задачи в основной папке; прочитаны там до начала работы.

Гостевой путь `/` показывает новый лендинг, авторизованный путь `/` сохраняет экран «Сегодня», а `/welcome` позволяет смотреть лендинг отдельно. Приложенный WorksWheel адаптирован под шесть демонстрационных слов: вращение кольцо → барабан, стрелки, колёсико, жесты, клавиатура. Темы, масштаб и анимации учитывают reduced motion. Общие Tailwind-токены задают цвета, типографику, боковые отступы и радиусы; прежние экраны используют их через CSS-переменные. Стек и API не менялись.

## Проверки

`pnpm db:generate`, `pnpm typecheck`, `pnpm build`, `pnpm format:check` и `git diff --check` прошли. В локальном браузере проверены лендинг и формы входа на узком экране в обеих темах; горизонтального переполнения не было. Кнопка колеса переводит карточки из кольца в барабан, клавиатура меняет активное слово. Новая ветка использует порт 5174 для локального просмотра; основной сервер на 5173 не менялся. Авторизованный учебный интерфейс визуально не проверялся в этой ветке, поскольку локальный API разрешает origin 5173, а отдельный предпросмотр работает на 5174. Это ограничение просмотра, не сборки.
