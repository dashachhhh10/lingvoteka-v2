## Цель и уточнения пользователя

Пока Railway не собирает новые версии, проверить клавиатурную навигацию основного учебного сценария на локальном интерфейсе. Не использовать личный аккаунт и не начинать Telegram Mini App.

## Решения и результат

Перед запуском подтверждено, что `DATABASE_URL` у локального API указывает на localhost, `FILE_STORAGE=local`, почта выключена. PostgreSQL отвечает на 127.0.0.1:5432 с разрешённым локальным доступом; обычная sandbox-проверка давала ложный отрицательный результат.

## Проверки

`pnpm dev` поднял Vite на `127.0.0.1:5173`, API на `3001` и worker. Создан временный локальный аккаунт `keyboard-qa-20261022-1228@example.invalid` и вручную добавлено одно синтетическое слово. В браузере проверено: Enter открывает добавление материала из «Сегодня», Tab переводит фокус к полю названия, текстовая форма принимает ввод, кнопка активируется; меню открывается Enter, закрывается Escape, переход к «Словарю» доступен Tab+Enter; карточка получает фокус Tab, переворачивается пробелом, оценки доступны Tab+Enter. Переключение на светлую тему отразилось в `aria-label` и на скриншоте. Временный аккаунт и связанная карточка удалены каскадно: `synthetic_account_cleanup=1`. Реальный урок этим тестом не проверялся.

## Следующие шаги / препятствия

Локальный `pnpm dev` оставлен работающим для просмотра по `http://127.0.0.1:5173/`, как пользователь ранее просила. Railway остаётся внешним препятствием публичного деплоя.
