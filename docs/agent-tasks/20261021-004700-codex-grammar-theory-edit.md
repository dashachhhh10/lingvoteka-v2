## Решения и результат

Добавлен `PATCH /api/grammar/:id/theory`: принимает ограниченную структуру теории, только для своей темы со статусом READY, сохраняет объяснение без изменения упражнений. В `GrammarDetailPage` добавлен редактор правила, примеров и ошибок с полями из общей Tailwind-темы. После сохранения фокус возвращается на кнопку редактирования; при смене темы черновик сбрасывается. В интерфейсе явно сказано, что упражнения остаются прежними и их стоит проверить после исправления правила. Roadmap отражает это решение.
