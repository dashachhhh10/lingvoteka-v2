## Цель и уточнения пользователя

После проверки настоящего урока пользователь заметила: новые слова не видны в карточках, свайп «не помню» заканчивает занятие, а карточки нельзя открыть для произвольной тренировки конкретной темы. Исправить это в рамках этапа 5. Следующий этап без согласования не начинать.

## Решения и результат

Установлено по коду: плановая очередь ограничивает новые слова `NEW_PER_DAY = 10`; UI получает снимок очереди один раз; ответ `Again` сохраняет срок FSRS, но в текущем сеансе больше не повторяется. При подтверждении материала новые слова создают карточки; старые слова могут совпадать по значению и не создавать дубликат.

Убраны суточный лимит новых карточек и предел 40 просроченных карточек в ответе очереди; новые слова идут первыми среди новых после уже просроченных. Добавлен API свободной практики по всем словам, лексической теме или части речи с изоляцией по владельцу. Практика только читает данные и не меняет FSRS. В React-сеансе ответы «Не помню» и «Трудно» добавляют карточку для ещё одной попытки; первая плановая оценка сохраняется на сервере, повторная внутри сеанса не отправляется до планового срока. Экран позволяет открыть подбор темы при наличии карточек и после завершения/пустой очереди. «Сегодня» при пустом плане ведёт к выбору темы.
