## Цель и уточнения пользователя

После подтверждения нового материала дать вход в карточки только его слов; разрешить отдельное повторение по любому материалу в любое время, наряду с темами. Продолжать этап 5, не переходить к этапу 6 без согласования.

## Решения и результат

На старте API общей очереди сначала возвращал просроченные карточки, затем новые. Фильтра материала не было, хотя связь слова с материалом уже хранится. Добавлен `materialId` в плановую очередь и свободную практику с проверкой владельца через связь материала со словом. В очереди конкретного урока новые слова идут перед просроченными; общая очередь не меняется. После подтверждения материала появляется ссылка на его карточки. В свободной практике теперь можно выбрать материал наряду с темой и частью речи; расписание FSRS при практике не меняется.

## Проверки
